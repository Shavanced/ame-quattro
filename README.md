## 📦 Installation

### Omarchy

The easiest way to install AME is with Omarchy's built-in theme installer:

```bash
omarchy-theme-install https://github.com/Shavanced/ame-quattro.git
```

After installation, select **AME** from your available themes.

"Ame" (雨) means "rain" in Japanese. I chose the name as a small tribute to the original Rainy Night theme, which was the foundation and inspiration for this theme.

But this is NOT a copy of the Rainy Night theme. I wanted to build upon that idea and create something of my own — my own interpretation of that rainy-night aesthetic, with a much larger wallpaper collection.

I currently have around 1,000 wallpapers downloaded, so it's honestly pretty hard to decide which ones to keep and which ones to remove. 😂 I haven't even tried all 1,000 of them yet.

For now, I've included some of my daily-driver wallpapers, and I'll keep adding and improving the wallpaper collection over time to make the theme even better.

And feel free to customize it however you want! Btw, I've left some old/legacy configs in the repo. You can delete them if you don't need them or if they make problems for you.

GitHub: https://github.com/Shavanced/ame-quattro

And finally, shout-out to ChatGPT for helping me build and customize this theme. 😄

Big thanks to the creator of Rainy Night for the original inspiration. 🌧️
